# 旅遊規劃 — 行程 · 分帳 · 打包清單

一個不用註冊、不用安裝、打開就能用的旅遊規劃網頁。

**線上版本：** https://yilinapan.github.io/travel/

---

## 有什麼功能

| 分頁 | 做什麼 |
|------|--------|
| 🧳 **我的旅程** | 管理多趟旅行、設定同行成員、設定外幣匯率、備份與還原 |
| 🗺 **行程** | 按天分頁的時間軸。每個行程點可記時間、地點、類型、備註、連結、金額 |
| 💰 **分帳** | 記錄誰付了什麼、這筆分給誰，自動算出「誰要轉給誰多少」，而且筆數最少 |
| 🎒 **打包清單** | 內建五大分類的預設清單，可勾選、可增刪、有完成進度 |

另外還有：

- **🔗 分享連結** — 產生一串網址傳給同行的人，他們點開就能看到行程和自己的分帳金額（唯讀）
- **外幣換算** — 設定匯率後，記帳時直接填外幣，結算自動換算成基準幣別
- **行程金額一鍵帶到分帳** — 行程點填了金額，按一下就變成一筆支出

## 資料存在哪裡（重要）

**資料只存在你這台裝置的瀏覽器裡，不會上傳到任何伺服器。**

這代表：

- ✅ 隱私最好，沒有人看得到你的行程
- ✅ 不用註冊帳號，沒有任何費用
- ⚠️ **換一台裝置、或清除瀏覽器資料，資料就會不見**

所以請定期到「我的旅程 → 備份與還原 → 下載備份檔」存一份。備份檔是一個 `.json` 檔，可以存到雲端硬碟，也可以傳給同行的人讓他們匯入。

### 分享連結的隱私

分享連結長這樣：

```
https://yilinapan.github.io/travel/#view=H4sIAAAA...
```

`#` 後面那段是壓縮過的行程資料。依照網路標準，**`#` 後面的內容不會被送到伺服器**，所以連 GitHub 也看不到你的行程內容。

分享連結是**當下的快照**：之後改了行程，要重新產生一次新的連結傳給大家。

## 怎麼用

### 線上用（推薦）

直接開 https://yilinapan.github.io/travel/ ，手機電腦都可以。加到手機主畫面就像一個 App。

### 在自己電腦跑

因為沒有用任何框架或套件，不需要安裝任何東西。不過瀏覽器對本機檔案有安全限制，建議用一個簡單的本機伺服器打開：

```bash
python -m http.server 8777
```

然後開 http://127.0.0.1:8777/

---

## 驗證分帳算得對不對

算錢的東西不能錯，所以分帳的計算有一整組自動測試。

**最簡單的方式：** 雙擊打開 `tests/test.html`，全部綠色就代表計算正常。

**用終端機跑：**

```bash
node tests/run.js
```

兩種方式跑的是同一份測試（`tests/settle.tests.js`），不會有兩套互相矛盾的結果。

## 刻意不做的事

| 不做 | 原因 |
|------|------|
| 嵌入地圖 | 需要申請 Google 金鑰、會產生費用。改成貼 Google Maps 連結，手機點了用原生地圖開更好用 |
| 自動抓匯率 | 要依賴外部服務，哪天對方關掉或改規則就壞了。改成自己填，穩定可靠 |
| 登入帳號 | 資料存在本機，不需要 |
| 拖曳排序 | 手機上容易誤觸。改用上移／下移箭頭，手機電腦都好按 |

## 技術說明

純 HTML + CSS + JavaScript，沒有用任何框架或套件，也沒有建置流程。
把檔案放進 GitHub 就直接是一個能用的網站，不會因為某個套件更新而壞掉。

支援淺色與深色模式（跟著系統設定走）。手機、平板、電腦都能用。
