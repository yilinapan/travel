# 雲端同步設定步驟

照這份做一次，之後手機和電腦就能接續編輯同一份資料。
**大約 10 分鐘，只要做一次。**

> 不想弄雲端也完全沒關係。不設定的話，工具一樣能用，只是資料各存各的裝置。

---

## 先知道兩件事

**資料會存在你自己的 Google 試算表裡。** 不是存在我這裡，也不是存在別人的伺服器。你隨時打開那張試算表就看得到全部內容。

**這個做法沒有帳號登入，安全性靠「那串網址很難猜」加上一組同步密碼**（第 7 步會設）。所以：

> ⚠️ **不要在工具裡填護照號碼、信用卡號、訂房密碼。**
> 行程、花費、打包清單這些放進去沒問題。

---

## 步驟

### 1. 建一張新的 Google 試算表

到 [sheets.new](https://sheets.new) 開一張新的，取個名字，例如「旅遊規劃資料」。

不用自己建任何分頁或標題，程式會自動建好。

### 2. 打開 Apps Script

在試算表的上方選單點 **「擴充功能」→「Apps Script」**。

會跳出一個新分頁，裡面有一個預設的 `Code.gs` 檔案，內容大概是空的 `function myFunction() {}`。

### 3. 貼上程式

把預設的內容**全部刪掉**，然後把這個專案裡 [`apps-script/Code.gs`](../apps-script/Code.gs) 的內容**整個複製貼上**。

按 **💾 存檔**（或 Ctrl+S）。

### 4. 先測試一下

在上方的函式下拉選單選 **「初始化試算表」**，按 **「執行」**。

第一次執行會要求授權：

1. 跳出「需要授權」→ 按 **「審查權限」**
2. 選你的 Google 帳號
3. 出現 **「Google 尚未驗證這個應用程式」** 的警告畫面
   → 這是**你自己寫的程式**，不是別人的。按左下角 **「進階」**，再按 **「前往『專案名稱』(不安全)」**
4. 按 **「允許」**

回到試算表看一下，應該多了 `旅程`、`行程`、`支出`、`還款`、`清單`、`_設定` 這幾張分頁，標題列也都填好了。

> 如果這一步成功，代表權限都給對了，後面會很順。

### 5. 部署成網頁應用程式

回到 Apps Script 分頁，按右上角 **「部署」→「新增部署作業」**。

1. 左邊「選取類型」旁邊有個 **齒輪 ⚙** 圖示，點它，選 **「網頁應用程式」**
2. 「說明」隨便填，例如「旅遊工具」
3. **「執行身分」選「我」**
4. **「誰可以存取」選「所有人」** ← 這一項最容易選錯，一定要選「所有人」
5. 按 **「部署」**

> **為什麼要選「所有人」？**
> 因為網頁是在你的瀏覽器裡跑的，它要能連到這支程式。
> 「所有人」的意思是「知道這串網址的人」，而那串網址只有你有。

### 6. 複製網址

部署完成後會顯示一串 **「網頁應用程式」網址**，長得像：

```
https://script.google.com/macros/s/AKfycby................../exec
```

**結尾一定是 `/exec`。** 按旁邊的「複製」。

> ⚠️ 不要複製瀏覽器網址列那一串（那是編輯器的網址，結尾是 `/edit`，貼了會連不上）。

### 7. 設定同步密碼

回到**試算表**分頁，**重新整理一次**，上方選單會多出 **「旅遊工具」**。

點 **「旅遊工具」→「設定同步密碼」**，輸入一組至少 8 個字的密碼，按「確定」。
（第一次點會再要一次授權，跟第 4 步一樣按「允許」。）

> **為什麼要密碼？**
> 「自動更新的分享連結」會讓旅伴的網頁連到這支程式。有了密碼，旅伴只讀得到你分享的那一趟行程和分帳，
> 讀不到打包清單、其他旅程，也改不了任何資料。沒設密碼的話，工具只會給「快照連結」。

### 8. 貼回工具

打開旅遊規劃工具 → 右下角 **⚙ → 設定** → 找到 **「雲端同步」** → 按 **「設定雲端同步」**。

把網址貼進去、填入**第 7 步的同步密碼**，順便幫這台裝置取個名字（例如「公司電腦」、「我的手機」），按 **「測試連線並儲存」**。

看到「連線成功！」就完成了。

### 9. 另一台裝置

在手機（或另一台電腦）上打開同一個網址，做**同樣的第 8 步**，貼上**同一串網址、同一組密碼**就好。

前面 1～7 步不用再做一次。

## 已經在用雲端同步了？更新成「自動更新的分享連結」

如果你在這個功能推出前就設定好雲端同步，要做一次下面的更新（約 5 分鐘）：

1. **更新程式**：試算表 → 「擴充功能」→「Apps Script」，把 `Code.gs` 內容**全部刪掉**，貼上這個專案最新的 [`apps-script/Code.gs`](../apps-script/Code.gs)，按 💾 存檔
2. **重新部署**：「部署」→「管理部署作業」→ ✏️ →「版本」選 **「新版本」**→「部署」。**網址不會變**
3. **設密碼**：回到試算表、重新整理，點 **「旅遊工具」→「設定同步密碼」**（同第 7 步）
4. **每台裝置都要填密碼**：網頁 → ⚙ → 設定 → 雲端同步 → **「修改設定」**，在「同步密碼」填同一組，按「測試連線並儲存」
   - 手機和電腦都要做。還沒填的那台會顯示「同步失敗」，填好就恢復
5. **Hermes** 也要帶密碼，見 [hermes-guide.md](hermes-guide.md)

做完之後，按 ⚙ → **分享**，拿到的就是自動更新的連結。

> 順序不重要，但第 3 步設完密碼之後，還沒填密碼的裝置會暫時同步不了，記得每台都補填。

## 之後怎麼運作

- 開啟網頁時會自動抓雲端最新的資料
- 你改了東西，停手幾秒後會自動存回雲端，旅程標題下方會顯示「同步中… / 已同步 ✓」
- 不想等的話，按右下角的 **⚙ → 同步** 立刻同步

### 分享給旅伴

按右下角 **⚙ → 分享**，拿到的是**自動更新的連結**：

- 只要傳一次。之後你改了行程，旅伴重新打開同一個連結就會看到最新的
- 旅伴只看得到那一趟的**行程和分帳**，打包清單不會分享出去
- 不想再分享時，在分享視窗按 **「停用連結」**，舊連結就打不開了
  （試算表「旅程」分頁的 **G 欄「分享代號」** 就是這個連結的代號，清空它也等於停用）

### 兩邊都改了怎麼辦

如果你在手機改了、電腦也改了，工具**不會自己決定留哪一份**，會跳出視窗問你，並告訴你雲端那份是哪一台裝置改的。

> 遇到這種狀況，建議先到「我的旅程」按「下載備份檔」存一份，再做選擇。

## 遇到問題

| 狀況 | 原因與解法 |
|------|-----------|
| 「連線失敗」、看到的是網頁不是資料 | 部署時「誰可以存取」沒選「所有人」。回去重新部署 |
| 「同步密碼不對」 | 網頁填的密碼跟試算表「旅遊工具 → 設定同步密碼」的不一樣。忘記的話，在試算表重新設一組，每台裝置再填一次 |
| 試算表上方沒有「旅遊工具」選單 | `Code.gs` 還是舊版，或貼完沒有重新整理試算表 |
| 分享時說「雲端還沒設定同步密碼」 | 做第 7 步，再到網頁的「修改設定」填密碼 |
| 網址貼了沒反應 | 複製到編輯器網址（`/edit` 結尾）了。要用 `/exec` 結尾那一串 |
| 改了 Apps Script 的程式但沒效果 | Apps Script 改完要**重新部署**：「部署」→「管理部署作業」→ ✏️ → 「版本」選「新版本」→「部署」。網址不會變 |
| 想換一串新網址（例如怕舊的外流） | 一樣在「管理部署作業」裡建立新的部署作業，會得到新網址，舊的可以停用。換了網址，之前傳出去的分享連結也會失效，要重新分享 |
| 試算表被我手動改壞了 | 直接在試算表裡修。欄位的意思見 [hermes-guide.md](hermes-guide.md) |

---

## 想自己手動改試算表？

可以。欄位格式和各種寫法（包含「指定項目」怎麼填）都寫在 [hermes-guide.md](hermes-guide.md)，
那份同時也是給 AI 助理看的說明。

改完之後，在工具裡按「我的旅程 → 雲端同步 → ⬇ 從雲端重新讀取」就會套用。
