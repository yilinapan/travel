# images — 行程示意圖放這裡

把圖片檔案放進這個資料夾，推上 GitHub 之後就會有永久網址。

在行程點的「示意圖」欄位，直接填短路徑即可：

```
images/kiyomizu.jpg
```

不用填完整網址。短路徑的好處：

- 分享連結不會因為圖片而變長
- 圖片跟著專案走，不會像外部網址那樣哪天失效

## 建議

- **先縮圖再放進來**：AI 生成的圖通常 1–2 MB，建議縮到寬度 800px、存成 JPG 或 WebP（約 100–200 KB），網頁才不會變慢
- **檔名用英文或數字**，避免中文檔名在不同系統上出問題
- 這是**示意圖**用的地方，不適合放整趟旅行拍的幾百張照片
